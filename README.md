# Victor Hugo — Portfolio

Portfólio pessoal em Next.js + TypeScript, com identidade Midnight Blue.

## Rodar no Windows CMD

Abra o CMD dentro da pasta do projeto e execute:

```cmd
npm install
npm run dev
```

Depois abra:

http://localhost:3000

## Alterar suas informações

Edite:

`data/portfolio.ts`

Nesse arquivo ficam:
- nome e cargo
- bio
- e-mail
- GitHub
- LinkedIn
- tecnologias
- projetos
- experiência
- formação

## Foto

A foto principal está em:

`public/victor-profile.png`

## Build de produção

```cmd
npm run build
npm start
```
